## 新增

- 房间和场景的图标都能自己换：右键侧栏里的房间名或智能页的场景卡片，选「自定义图标…」，可以直接贴 SVG 代码、导入 .svg 文件，或选一张 PNG 图片；房间页右上角那枚大图标点一下也能换。编辑场景 / 自动化时，基础信息卡左上角那枚图标也能直接点开换（新建场景保存后再换）。SVG 图标还能统一换成白色、蓝色等任意颜色，代码框里的内容从顶部开始显示。上传的图会铺满整个图标位，不会在四周露出底色；选图标弹窗也收紧了代码框高度，正常使用时不用滚动。换完侧栏、房间页、首页分组、场景卡片和编辑弹窗会一起更新，右键选「恢复默认图标」随时能回到原来那套画法
- 房间页的大图标和场景编辑里的图标现在也能直接右键「恢复默认图标」，不用先打开图标弹窗；侧栏房间、智能页和首页场景卡原来的恢复入口都保留

- 桌面分区背景色和 SVG 图标颜色都能用调色盘挑任意颜色：预设色最右边的彩色圆点打开调色盘，拖色相、饱和度和明度，也能直接输入 HEX；桌面组件外观弹窗和设置页的「分区外观」都能用，选完立刻生效；图标颜色行的色点、原色按钮和色值输入框也对齐并留出了间距
- 选图标弹窗的 SVG 模式里多了素材站入口：导入按钮右侧列出 svgrepo.com、Lucide、Tabler、Iconify，点一下就用默认浏览器打开对应网站，找 SVG 图标不用再自己记网址
- 首页「环境与能耗」新增用水与用气数据卡：燃气/电热水器报出用水升数、水流量和水温，燃气热水器还能看到每次洗澡的用气量；今天的逐小时和近 7 天趋势都排在原有趋势卡位置，燃气热水器还能切到近 30 天。家里有净水器时再出现「水质」卡，显示出水 TDS、进水 TDS 与滤芯余量
- 首页「环境与能耗」标题旁多了「编辑」按钮：弹出的窗口里逐张开关温度、湿度、用电、用水、用气、水质卡，改完立刻生效，开关状态下次启动还记得；点「恢复默认」回到全部显示
- 首页「用水」「用气」卡改成和温度、湿度卡一样的单张曲线：数据取自米家「使用记录」同一套云端统计，大数字是当前范围的累计用量，卡上能切今日 / 7 / 30 天 / 本月 / 半年，悬停能看到某小时或某天用了多少；本月与半年口径的水按「吨（m³）」显示，和米家「使用记录」页的月账一致，只有一台设备时也不会再出现「全部设备（叠加）」这一项，刚启动先用上次拉到的数据，之后每十分钟自动更新
- 用电卡的范围也多到近半年和近 1 年，长范围自动改成曲线，几百个点不会挤成一片柱子；用水、用气、用电卡角上的范围与设备下拉只显示设备名，不再把房间名挤在同一枚小胶囊里，按钮也留出了更宽的显示位置
- 首页「数据看板」新增体重卡：大数字是最近一次称重的体重，旁边带体脂率、BMI 和较上次的变化，下面铺体重曲线，可在近 30 天 / 90 天 / 半年 / 1 年之间切换，悬停气泡里显示的是称重日期；右上角能切换家庭成员，各看各的记录。数据与米家 App 里体脂秤的「历史记录」同源，只有带阻抗的测量才算得出体脂率，只称体重时卡上会写明「仅体重」

- 首页每个房间标题右侧会显示「N 盏灯亮着」，房间页顶部横幅里这行数量与「一键全关」跟设备总数、当前开启、离线几个数值排在一起；点「一键全关」就把这间屋里开着的灯一次关掉，房间收起后也能看到数量
- 首页「数据看板」多了一排空气小卡：PM2.5、PM10、甲醛、TVOC、二氧化碳各一枚，一枚卡只报一个读数，右上角的小胶囊按数值标出「优 / 良 / 达标 / 偏高 / 超标」并跟着变色（绿 / 琥珀 / 红），读数右下的浅灰小字是数据来自哪个房间，鼠标悬停能看到完整读数和来源设备。读数取自家里能测这些指标的设备（净化器、空气质量检测仪这类），每台设备一次读数只取一台、按在线优先挑，不做全屋平均；没有能测某项的设备时那枚卡铺示例读数，卡上不写多余说明，鼠标移入才浮出「预览」小标，接入设备后自动换真读数。五枚卡各用一种色相——雾蓝、砂褐、玫粉、柠檬、青，左侧小色条、标题和读数同色，卡面再铺一层同色淡底，深浅主题各取对应的一档；读数颜色还会跟着档位走，正常时保持自己的色相，偏高转琥珀、超标转红，和右上角胶囊同一套判断。五枚卡跟着大卡一起收进「编辑」弹窗，可以单独关掉、也能拖动排序
- 「数据看板」的编辑弹窗顶部多了「更新频率」：可以选随设备刷新、1 分钟、5 分钟或 15 分钟，按选好的节奏重算看板上的读数和曲线，调慢后数字不会一直跳；只影响这块看板，下面的设备卡和首页统计照旧，改完立刻生效、下次启动还记得











## 优化

- 首页「数据看板」的入场换成了更缓的淡入上浮：标题和第一张卡先轻轻浮出，后面的卡片按同排顺序一张接一张跟上，不再像整块被一下子推到位
- 首页「数据看板」里的读数在数据刷新时不再瞬间跳变：大数字会从旧值顺着滑到新值，曲线和柱子也会从原来的形状柔和地变过去；后长出来的图表同样淡入，不会整块突然亮起
- 「数据看板」编辑弹窗里每张卡左边多了一个六点抓手，按住就能上下拖动，首页卡片会按拖出来的顺序排列；松手后顺序立即生效并记住，「恢复默认」也会把顺序一起还原
- 首页「数据看板」的卡片改成按行均分铺满：七张大卡会排成 3 / 2 / 2，下面两行的两张卡各自拉宽填满整行，不再出现最后一行只剩一张、右边空一大块的情况；只剩一张卡时宽度也有上限，不会被拉得过宽
- 「数据看板」编辑弹窗里每张卡的说明不再带时间范围（近 24 小时、今日、近 30 天这类都去掉了），只讲这张卡能看什么；实际看多久仍由卡片自己的范围下拉决定
- 首页「数据看板」的卡片现在会依次轻轻移入：刚拉完数据、从别的页面切回来，或者在「编辑」里重新打开某张卡时，卡片不再整块突然出现，而是按同排顺序一张接一张淡入
- 首页的段落标题与右侧的小字说明改为和卡片左右边缘对齐，标题不再比卡片左缘探出半格、说明也不会越过卡片右缘；房间标题、快捷场景标题和「更多」按钮同样跟着收进一格
- 设备卡现在统一等高，不会再因为读数标签换行而一张高一张矮；卡片之间上下左右的间距也统一成同样一格，房间标题贴紧了下面这排卡片
- 设备卡上的「离线」「灯组」角标改成紧贴设备名称后面，不再被推到行尾；读数标签之间的缝也收窄了一点，两枚并排刚好放得下，标签行可以一直排到电源键前面一点点；读数多到一行放不下时，卡片上先让出房间名，把整行宽度留给读数，标签再多也收在卡片里面，不会顶出卡片边缘
- 首页「环境与能耗」改名「数据看板」：这一块现在除了温湿度和用电用水用气，也放体重这类身体数据，原来的名字盖不住了；卡片本身和「编辑」入口都没有挪位置
- 甲醛等很小的读数会保留有效小数，例如 0.003 mg/m³ 不再被显示成 0；小数末尾的 0 会自动省略
- 设备卡片上的多项读数改为逐段换行显示，随卡片内容垂直居中；离线和灯组标签紧跟在设备名称后方，标签始终完整显示；鼠标悬停仍可查看完整数值，长读数不会再把卡片撑宽或挤压相邻卡片；设备名过长时自动省略并可从悬停提示看全名，不会再压到右侧电源键底下
- 首页「环境与能耗」趋势卡的阴影不再被卡片边缘裁掉，卡片和下方内容的层次恢复正常
- 首页「数据看板」里家里没有对应设备的卡片不再空着：默认也会铺出来，先展示一份示例预览数据，鼠标移入卡片才浮出「预览」标识，悬停有说明、点一下能看完整弹窗；接入对应设备并同步后自动换成真实读数，第一次遇到预览卡还会自动说明一次。把卡全部关掉时，首页的「数据看板」会整块收起，不再留空标题；之后在「设置 → 通用 → 首页」可以重新打开。「编辑」弹窗里也会把缺设备的卡标成「暂无可用设备 · 打开后显示预览数据」
- 首页「数据看板」全部卡片关掉后整块收起，标题、编辑入口和提示行都不再留在首页；想恢复时到「设置 → 通用 → 首页」打开「数据看板」开关，卡片会一起恢复显示，之前拖好的顺序也还在
- 在「数据看板」编辑弹窗里把卡片全部关掉后点「完成」或直接关闭弹窗，会先弹出一层重点提示，说明首页这一整块会消失、之后去哪里重新打开；点「返回调整」留在弹窗继续勾选，点「仍然隐藏」才真正收起
- 侧栏房间名右侧那枚「灯还亮着」的小灯泡在浅色模式下太淡，看不清是哪个房间开着灯；现在灯点放大一圈、换成透着高光的亮暖黄灯身，外面再补一圈暖光晕，浅色模式也能一眼认出来
- 设备详情顶部的读数卡按抽屉宽度自动分列，最多排 3 张：温度、湿度、PM2.5 这类三项一行就放得下，不再折到第二行留出半张空位
- 设备卡片上的读数改成一枚一枚的小标签，和房间名排在一行；排不下时整枚换到下一行，不会再出现被折成两截的读数、行尾也不会留一个孤零零的点，鼠标悬停仍能看到完整数值
- 设置里更新区域那行讲更新来源与技术细节的长说明已经去掉，这一块只留版本状态、通道提示和按钮，看起来清爽不少
- 设置里的「隐藏开关」改叫「隐藏开关设备」，名字一眼就说清是隐藏哪一类设备
- 桌面分区的外观页里「背景浓度」能一直拉到 100%，滑杆到头就是一块实心底色，不会再在 72% 停住；默认浓度还是原来那一档
- 设备详情页顶部改成图标在左、名称在右：图标放大一圈并和名称上沿对齐，名称独占一整行，房间和右侧「桌面 / 隐藏」两颗胶囊挪到名称下面一行，长设备名不再被按钮挤成两截
- 桌面空调卡上的模式切换钮原来在浅色轨道里偏上、下面空一截，右边还空着一块；现在整组垂直居中，几个模式钮按轨道宽度平分，选中块和轨道一样铺满
- 桌面空调卡与设备详情里的风速档位柱改成上下对称居中，一档二档那几根矮柱不再贴着轨道底边往下沉
- 空调分区的「⋯」菜单不再列出点不动的项：空调分区只挂一台空调、也没有标题栏，「添加设备」和「重命名」原本点了没反应，「拖拽卡片可排序」也没卡可排；现在只剩「添加分区 / 外观设置 / 关闭空调分区」三项
- 环境与能耗卡片上的下拉触发按钮文字统一压到次级灰，和箭头同一档，不再比主读数还亮；打开设备来源或时间范围其中一个下拉时，另一个也会留在卡片上，不会突然消失
- 首页趋势卡的曲线区统一加高到至少 72，并会占满卡片里的富余高度：温度、湿度、用电、用水、用气、体重、水质这些卡不再把曲线缩在底部，卡片被同排拉高时曲线也会跟着铺满
- 首页「用气」卡从曲线改成每日柱状：一天一根柱子，今天那根高亮，柱后一条淡虚线标出上一段同期的日均，哪几天用得多、这一期比上期是多是少一眼能看出来；半年这种上百格的范围仍用曲线
- 首页「体重」卡从曲线改成点阵：每次称重画一个点，没称重的日子不会再被一条线连过去假装连续；背后一层淡色区间带标出这些天体重落的范围，中间一条虚线是平均值，悬停仍显示具体称重日期
- 首页顶部五张统计卡（在线设备 / 总设备 / 灯光 / 窗帘 / 空调）不再自带一套偏蓝的渐变底色，换成和趋势卡、设备卡一样的卡片色，深浅主题下都和旁边的卡片一个色，靠一圈极淡的描边分出边界
- 标题栏只留「MiHomeHub · 控制中心」，前面那枚「智能家居」小标签和名字里的「米家」都去掉了
- 任务栏上只显示「MiHomeHub」，不再把「控制中心」几个字跟在后面；窗口里自己的标题栏不做改动
- 首页问候语下面那行只留时间和日期，不再跟在后面显示「已登录 / 未登录」，登录状态改用设置里的那行来确认
- 首页「数据看板」和「快捷场景」的标题往卡片贴近了一格，标题不再悬在卡片上方老远，一眼就能看出这块标题管的是下面哪一排卡
- 首页「数据看板」和「快捷场景」的标题前各加了一枚小图标：看板是三根高低不同的柱子（柱状图），场景是那颗闪光，两段不用读字也能先认出来；图标跟标题的中线对齐、同一档灰

## 修复

- 部分第三方灯具（比如 trytogo 落地灯）以前卡片上只有通用灯泡线框；现在会显示这台设备在米家里的图片，细长渐变灯条和米家列表里看到的一致
- 「添加到桌面组件」的分区列表里不再出现媒体分区和空调分区，设备也加不进这两块；以前误加进去的设备会自动清掉
- 桌面分区里本该有的设备不再凭空少一张：并进灯组的灯、并进多键开关的单键、以及开着「隐藏开关设备」时被收起的开关，现在都能在分区里正常显示，不会再出现「写着 3 台设备、只显示 1 台」
- 个别第三方插座（比如电小酷）详情页里的电压、电流后面跟着一个「none」，例如「650none」；现在按读数类型补上单位，显示成「650V」「2.3A」
- 这类插座把耗电量按 0.01 度或瓦时上报，用电统计曾把 62 度算成 61921 度；现在按规格里写明的单位换算成度，今日用电与近 7 / 30 天的数字都回到正常量级
- 文光汇这类第三方计量插座以前详情里只有开关，功率、电压、电流、耗电量都不出现；现在这些读数都会作为读数卡列出来，点亮后还能显示在主页设备卡上
- 设备详情顶部的读数卡以前只有「温度 / 湿度」能被点亮，PM2.5、CO₂、噪声这类读数的小房子一直是灰的，明明已经在主页和桌面卡片上显示也照不出来；现在点亮状态与实际一致，点一下就能真正把它加上或从卡片上关掉
- 浅色模式下已关闭的开关以前几乎看不出形状：轨道和卡片几乎同一个白，亮一点的屏幕上整颗开关直接消失（截图里还能勉强看出淡边）；现在关闭态的轨道压深一档、外面带一圈细边，在纯白卡片和磨砂白面板上都能一眼分清开与关，设置、设备详情、场景编辑和抽屉里的开关都跟着变清楚

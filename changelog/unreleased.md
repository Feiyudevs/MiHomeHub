# 未发布

## macOS 版（实验性）

- 新增 macOS 版：同一套 C# / .NET 10 + Avalonia 代码，不用改 Windows 端一行，也能编出 `.app` 与 `.dmg`（Apple Silicon 与 Intel 各一份）。设备控制、桌面分区组件、全局快捷键、托盘菜单、开机自启、更新检查均可用
- macOS 的桌面分区组件改用 AppKit 等价实现：贴访达桌面层（比图标层高一层）、点它不抢焦点、拖动与拉伸和 Windows 版一致；毛玻璃用自建的 `NSVisualEffectView` 配 8px 圆角裁剪，观感对齐 Windows 的亚克力
- 全局快捷键改走系统 `RegisterEventHotKey`：不需要「辅助功能」权限，可同时注册多条，每条绑定各自的设备；没授权时也能在设置窗口里直接按键录入
- 开机自启用 launchd（`~/Library/LaunchAgents`），写入失败不再带崩启动，只在设置页写明原因
- 凭证改存钥匙串（`Security.framework`），并给读取加了超时，避免授权弹窗无人点击时卡住启动线程
- 新增 macOS 打包流水线 `.github/workflows/macos-release.yml`：出 `.dmg` + `update-macos-<rid>.json` + `SHA256SUMS-macos-<rid>.txt`，与 Windows 的 `update.json` 通道互不覆盖
- 这一版暂未适配 macOS 的两项 Windows 专属功能：监控分区（摄像头实时预览）与桌面数据卡；macOS 上这两项入口不显示

## 优化
- 设置页的「桌面组件」一栏改成方卡分组：媒体、空调、监控、桌面数据卡各占一块卡，开关就压在对应那张卡上，摄像头下拉和「管理」也收进各自的卡里；「双击隐藏组件」「移入自动展开」另归到「桌面交互」两张卡，找哪一项都不用再在一长条开关里上下认
- 摄像头的分辨率 / 帧率小标从画面上挪到了标题行：抽屉里跟在「实时画面」右边，放大窗口里跟在状态文字后面，播放时才出现，不再压着画面
- 首页「数据看板」的编辑弹窗里，每张卡右边多了「＋首页」「＋桌面」两枚开关：一张卡放不放首页、放不放桌面组件在同一个地方勾选，两枚互不影响，关掉桌面只收起、位置和大小都保留；没有对应设备的卡首页和桌面都铺示例读数，接入后自动换真数据，卡下只留一句「暂无设备 · 显示示例数据」。新加到桌面的卡会落在本程序组件最多的那块屏上找空位，不再固定回主屏；设置 → 桌面组件里的数据卡方砖收成一行「已投到桌面 N 张」，点「管理」就回到这个弹窗
- 浅色主题下摄像头画面区不再是一整块黑：改成浅灰蓝的底、细描边和白色圆盘播放键，字和三角也跟着换成深色，抽屉和放大窗同时生效
- 摄像头连接中的等待换成了一圈转动的进度环（细底环 + 一段亮弧），不再是原来那条细进度条；「声音已接上但一直是静默」这条提示现在会自己撤掉，真出声了就不再挂着

- 场景编辑里拖动「执行顺序」时那一条落点线改成两端渐隐收口，短短一条细线不再两头生硬截断；数据看板编辑里的卡片落点线也换成同一套渐变
- 桌面数据卡的曲线 / 柱形现在贴到卡片最底部，圆角以内整块铺满，卡片下方不再留一条空白
- 桌面数据卡右上角那两行小字（体感、水温 / 进水、最少 / 最多这类）平时收起来，鼠标压到卡片上或展开下拉时才淡入，卡片安静时只剩标题、读数和曲线；显隐不影响布局，读数不会跟着跳
- 首页「数据看板」下面那排空气小卡开够 4 枚以上时，会一起拉宽铺满整行，右边不再空出半格；只剩两三枚时仍按原来的窄卡排，不会被拉成一条长条。拉宽后单张也有上限（约 260 一格），窗口再宽也不会把小卡撑成大宽板，卡片始终靠左紧排、多出的空间留在行尾
- 摄像机这类设备的「高级设置」不再满屏英文：分组标题、属性名和下拉里的取值都会显示成中文（摄像机控制、画面翻转、夜视、时间水印、宽动态范围、微光全彩、录像模式里的不录像 / 持续录像 / 移动录像、推流状态、视频编码、鉴权方式等），画面翻转的角度也写成「0°」；其它设备规格里只带英文的项同样会跟着换回中文
- 桌面数据卡右上角两枚下拉改成墨色玻璃 + 白字：胶囊和展开菜单都是半透明压深色、卡面颜色透得出来，边缘一圈淡白描边加柔和投影；胶囊悬停、菜单行悬停都叠一层白色带透明度再亮一档，当前选中行最亮并加粗，文字和展开箭头一律白色，压在任何颜色的卡面上都读得清
- 桌面组件上的次级文字改用白色带透明度显示：卡片标题、单位、右侧的「体感偏冷」「最低 … 最高 …」、脚注、下拉标签和小卡说明都换成中性白，浓淡只靠深浅分档，压在紫、黄这类彩色卡面或渐变上都清爽，不再发灰发闷；换成纸白卡面时自动回到压深的那一套
- 摄像头抽屉的「实时画面」定稿：上面一行标题和状态（未打开 / 正在连接 / 播放中），画面按 16:9 出高度铺满卡片宽度、上下不留黑边，播放时左上角浮出「1920×1080 · 20 fps」这类小标；没播放时中间是一个「▶」和一句提示，点下面那颗「打开实时画面」才开始连，连上之前画面区里转圈并写「正在连接摄像机…」，出第一帧才换成画面。播放时下面三颗各自独立的胶囊按钮（停止、声音、放大，各带图标），不再共用一条底槽。原来那套「准备本地画面源」的三步说明、播放器打开、地址输入、复制配置 / 诊断、安全提示和「去安装 HEVC 组件」都清掉了
- 桌面组件外观里的「毛玻璃」开关去掉了：卡片统一保持磨砂玻璃，浓度滑杆调的是底色本身，不再留一个点了看不出变化的开关；旧配置里关过的，升级后自动回到磨砂
- 智能页的场景图标整批换成了圆润线稿，而且按场景名分得比原来细：灯按「开灯 / 关灯 / 灯带 / 氛围灯」拆成不同图形，中控按键、无线开关这类只有按键的场景用遥控器图标，「关电器」用电源图标，不再一堆场景挤在同一枚灯泡上；窗帘、空调、热水器、清洁、观影、电竞、晚安、起床、回家、离家、工作、欢迎、语音播报、燃气、漏水这些场景各有一枚自己的图标，实测 83 条场景全部能认出来、没有一条落回星芒。图标底块也统一成一样的圆角，所有线稿的外框都归一到同一尺寸、同一中心，在底块里绝对居中、大小一致，不再有的撑满有的偏左上；列表卡片、首页快捷场景、桌面分区和编辑弹窗看起来是一整套
- 首页「数据看板」的七张大卡整体收矮一档：卡高从 176 降到 150，曲线区让出这一截，标题、读数和右侧说明照样放得下，一排卡看起来更紧凑
- 设置 → 桌面组件里每项的小字说明都收成一句：只讲这一项管什么，不再把指标名从头到尾列一遍，也不在后面重复「关掉后不会自动放回」这类话
- 首页各张趋势卡的标题只留指标名（温度、湿度、用电、用水、用气），看的是今天还是近 30 天、半年，交给卡片右上角那枚范围下拉表示；标题里不再出现「今日」「近 7 天」「至 8/20」这类时间说法，同一张卡切范围时标题也不再跟着变。桌面上的数据卡跟着一起改

## 修复

- 在 Windows 10 上拖动桌面组件（数据卡与设备 / 媒体 / 空调 / 监控分区）、或拖它们的右下角改大小时不再发涩掉帧：以前每跟手一帧都要把卡片背后的磨砂与投影重算一遍，Win10 的系统合成顶不住这份开销，拖动就一卡一卡；现在拖的过程中只让组件跟着手走，磨砂和投影在松手后一次性补回来，落点看起来和以前一样

- 摄像头抽屉里不会再冒出「连不上画面源（由于目标计算机积极拒绝…）确认 go2rtc 已启动」这类提示：那条是早前外接画面源的自检文案，画面改成程序内置以后已经不该出现，抽屉打开时也不再去探那个旧地址
- 摄像头预览底部不再挂一条杂色：码流里标的编码高度是 1088，实际画面裁到 1080，之前按 1088 上屏把多出来的空行也画了进去；现在按真正解出的尺寸显示，状态里写的也是实际分辨率- 桌面数据卡刷新时只换读数，不再整卡动一下：以前每次自动刷新都会先把曲线藏起来再淡入、数字从旧值再滚一遍，几张卡同一拍刷新，看着就是一排卡一起眨；现在新读数和新曲线直接落到卡上，只有真的没数据时才换成提示文字
- 双击隐藏桌面组件后再显示，卡片和磨砂背景都不会再连着闪：以前新卡窗上屏时先亮一帧没磨砂的、随后才糊上，还要靠把窗口缩 1px 再还原去强行要一帧；更要紧的是显示后的一个多秒里还在每 60ms 把卡往桌面底压一次，每压一次玻璃就被挤到卡下面再重钉、背景重采一遍——现在磨砂在卡片上屏前备好、同一拍一起出现，压底只在样式真被系统重置时才补，背景不再连闪
- 首页「数据看板」右上角的两枚下拉，点卡片空白处收起时不再一起闪一下：以前收起那一刻光标明明还压在卡上，两枚小胶囊会先淡出、下一帧再淡回来，看着像眨了一下眼；现在收起后先保持原样，等指针真的离开卡片（或下一次移动时已经不在卡上）才淡出
- 双击桌面上的程序、文件夹或文件图标时，桌面组件不会再跟着一起隐藏：以前点在图标上也被当成「双击桌面空白」，现在只有真的点在没图标的空白处才切换显隐，双击图标只做图标自己的事

- 部分第三方灯具（比如 trytogo 落地灯）以前卡片上只有通用灯泡线框；现在会显示这台设备在米家里的图片，细长渐变灯条和米家列表里看到的一致
- 「添加到桌面组件」的分区列表里不再出现媒体分区和空调分区，设备也加不进这两块；以前误加进去的设备会自动清掉
- 桌面分区里本该有的设备不再凭空少一张：并进灯组的灯、并进多键开关的单键、以及开着「隐藏开关设备」时被收起的开关，现在都能在分区里正常显示，不会再出现「写着 3 台设备、只显示 1 台」
- 个别第三方插座（比如电小酷）详情页里的电压、电流后面跟着一个「none」，例如「650none」；现在按读数类型补上单位，显示成「650V」「2.3A」
- 这类插座把耗电量按 0.01 度或瓦时上报，用电统计曾把 62 度算成 61921 度；现在按规格里写明的单位换算成度，今日用电与近 7 / 30 天的数字都回到正常量级
- 文光汇这类第三方计量插座以前详情里只有开关，功率、电压、电流、耗电量都不出现；现在这些读数都会作为读数卡列出来，点亮后还能显示在主页设备卡上

- 新增内置画面源（go2rtc，MIT）：随程序内嵌、首用释放到数据目录、按设备生成配置并选随机本机端口，主进程退出时一并回收；新增 `--camera-live-probe` 只读自检口核对解码链路

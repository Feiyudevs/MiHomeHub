# 米家控制中心 · UI 设计规范

> 版本 1.0 · 对应实现 `mijia-panel.html`  
> 风格锚点：macOS 系统设置的信息密度 + Apple Home 的卡片温度 + 小米冷紫强调色  
> 适用：PC 桌面智能家居控制面板（深色 / 浅色双主题）

---

## 1. 设计原则

| 原则 | 说明 |
|------|------|
| **简约** | 卡片无描边，靠底色与轻投影分层；去掉多余分割线 |
| **呼吸感** | 侧栏导航间距加大；分区标题后不接横线 |
| **圆角统一** | 内容面板、卡片、控件均使用大圆角体系 |
| **冷紫主色** | 强调色为偏紫冷色调，开启态用淡紫底而非硬边框 |
| **组件化卡片** | 设备、场景、统计、自动化均为独立卡片单元 |
| **双主题对等** | 深浅色使用同一套语义 Token，仅替换色值 |

## 2. 色彩系统

### 2.1 语义 Token（深色 / 浅色）

| Token | 深色 | 浅色 | 用途 |
|-------|------|------|------|
| `--bg` | `#07090E` | `#E6EAF1` | 页面最底层背景 |
| `--panel` | `#0E1118` | `#F7F9FC` | 内容大圆角面板 |
| `--card` | `#1A1F2C` | `#FFFFFF` | 卡片底色 |
| `--card-2` | `#222838` | `#F0F3F8` | 次级卡片 / hover 底 |
| `--hover` | `#282F42` | `#E8EDF5` | 悬停反馈 |
| `--line` | `rgba(255,255,255,.07)` | `rgba(15,23,42,.08)` | 极弱分隔（慎用） |
| `--line-2` | `rgba(255,255,255,.12)` | `rgba(15,23,42,.14)` | 次级分隔 |
| `--text` | `#EEF1F6` | `#0F172A` | 主文字 |
| `--text-2` | `#99A1B3` | `#5A6478` | 次文字 |
| `--text-3` | `#646C7E` | `#8A93A6` | 辅助 / 说明文字 |

### 2.2 强调色与功能色

| Token | 深色 | 浅色 | 用途 |
|-------|------|------|------|
| `--accent` | `#7C5CFC` | `#6D5BE3` | 主强调：开关、按钮、进度条 |
| `--accent-2` | `#9B8CFF` | `#5B4BC9` | 强调 hover / 图标 |
| `--accent-soft` | `rgba(124,92,252,.14)` | `rgba(109,91,227,.12)` | 选中底、柔和高亮 |
| `--warm-text` | `#9B8CFF` | `#5B4BC9` | 强调色文字（标签、激活导航） |
| `--green` | `#2FD573` | `#16A34A` | 在线 / 正常 / 成功 |
| `--blue` | `#4D8DFF` | `#2563EB` | 信息 / 链接 |
| `--amber` | `#FFC53D` | `#D97706` | 警告 / 注意 |
| `--purple` | `#A78BFA` | `#7C3AED` | 次强调 / 装饰 |
| `--cool` | `#7EB0FF` | `#1D4ED8` | 冷色数据（湿度等） |

### 2.3 半透明表面层

| Token | 深色基底 | 用途 |
|-------|----------|------|
| `--surface` | `rgba(255,255,255,.05)` | 图标底、hover |
| `--surface-2` ~ `--surface-5` | 白色 4%–8% | 芯片、徽标、输入框 |
| 浅色对应 | `rgba(15,23,42,.035~.07)` | 同上 |

### 2.4 开启态设备卡

```
深色: linear-gradient(160deg, rgba(124,92,252,.14), rgba(124,92,252,.05) 55%, var(--card))
浅色: linear-gradient(160deg, rgba(109,91,227,.12), rgba(109,91,227,.04) 55%, var(--card))
```

- **不使用** 顶部色条或硬边框  
- 仅靠淡紫渐变底 + 开关/图标强调色区分开启

### 2.5 渐变

| 场景 | 深色示例 |
|------|----------|
| 主按钮 | `linear-gradient(135deg, #7C5CFC, #8B7CFF)` |
| 品牌 Logo | `linear-gradient(135deg, #7C5CFC, #9B8CFF)` |
| Hero 背景 | 径向紫/蓝光晕 + 线性卡片渐变 |
| 场景大卡 | `linear-gradient(150deg, {场景色}33, {场景色}12 55%, var(--card))` |

场景标识色可多彩（回家紫、离家蓝、睡眠靛、起床琥珀…），系统强调色保持冷紫。

## 3. 字体与排版

### 3.1 字体栈

```css
"Segoe UI Variable Text", "Segoe UI", "PingFang SC",
"Microsoft YaHei UI", "Microsoft YaHei", system-ui, sans-serif
```

### 3.2 字号阶梯

| 层级 | 字号 | 字重 | 用途 |
|------|------|------|------|
| Display | 24px | 700 | Hero 问候语 |
| 大数字 | 44–56px | 750 | 温度、抽屉温控（`font-variant-numeric: tabular-nums`） |
| H2 | 19px | 700 | 房间横幅标题 |
| H3 | 16px | 700 | 场景大卡标题 |
| 卡片标题 | 13.5–14.5px | 650 | 设备名、区块标题 |
| 正文 | 13–14px | 400–500 | 按钮、导航、表单 |
| 辅助 | 11.5–12.5px | 500–600 | 副标题、状态、单位 |
| 微标 | 10.5–11px | 600–700 | 徽标、图例、Tag |

### 3.3 数字

所有数值、时间、百分比使用：

```css
font-variant-numeric: tabular-nums;
letter-spacing: -0.4px ~ -2.5px; /* 大数字收紧 */
```

### 3.4 行高与字距

- 正文 `line-height: 1.5`
- 导航 `letter-spacing: normal`
- 分组标签 `letter-spacing: .08em`（全大写/小标题感）
- Tag `letter-spacing: .03em`

## 4. 圆角体系

| Token | 值 | 用途 |
|-------|-----|------|
| `--r-lg` | **20px** | Hero、房间横幅、温度卡、场景大卡 |
| `--r` | **16px** | 标准卡片（设备、统计、自动化、设置） |
| `--r-sm` | **12px** | 导航项、小容器 |
| 内容面板 | **20px**（四角） | 主内容区大面板 |
| 控件 | 10–12px | 按钮、搜索框、输入 |
| 芯片 / 开关 | 20–22px | 全圆角胶囊 |
| 图标底 | 12–14px | 设备/统计/自动化图标容器 |

**内容面板圆角规则：** 四角均为 `20px`，不与标题栏粘连；标题栏在面板之外、窗口最顶。

## 5. 间距与布局

### 5.1 页面结构

```
┌─────────────────────────────────────────────┐
│  窗口标题栏 48px（品牌 | 搜索 | 主题 | 窗口按钮）│
├──────────┬──────────────────────────────────┤
│          │                                  │
│  侧栏     │   内容面板（radius 20px 四角）      │
│  200px   │   padding: 20px 22px 28px        │
│          │                                  │
└──────────┴──────────────────────────────────┘
```

- 外边距：标题栏下 `app` 底部/左右约 `10px`
- 侧栏与面板间距：`margin-left: 4px`
- 分区标题上下：`26px / 12px`
- 卡片网格 gap：`13–14px`
- 卡片内边距：`15–18px`

### 5.2 侧栏导航

- 导航项：`padding: 11px 12px`，`border-radius: 12px`，项间 `gap: 4px`
- 激活态：左侧 `3×18px` 圆角指示条 + `--accent-soft` 底
- 分组标签：上下留白加大（`18px 10px 8px`），无分割线
- 底部「我的家」：无顶部分割线，仅靠间距

### 5.3 响应式

| 断点 | 行为 |
|------|------|
| ≤1180px | 统计 2 列；场景条 3 列；环境单列 |
| ≤900px | 侧栏收至 64px 图标栏；场景 2 列；Hero 纵向堆叠 |

## 6. 阴影

| Token | 深色 | 浅色 | 用途 |
|-------|------|------|------|
| 默认投影 | `0 1px 2px rgba(0,0,0,.2)` | `0 1px 2px rgba(15,23,42,.04)` | 卡片静态轻投影 |
| `--shadow` | `0 8px 28px rgba(0,0,0,.35)` | `0 8px 28px rgba(15,23,42,.08)` | 悬停 / 浮层 |
| `--shadow-strong` | `0 12px 40px rgba(0,0,0,.5)` | `0 12px 40px rgba(15,23,42,.12)` | Toast、抽屉、面板 |
| 面板 | `0 1px 2px … + 0 16px 48px …` | 类似更轻 | 内容大面板 |

**规范：** 静态卡片不堆叠多层阴影；hover 再升一档。禁止彩色大范围 glow（场景卡光晕 opacity ≤ .5）。

## 7. 动效

| 场景 | 时长 | 缓动 | 说明 |
|------|------|------|------|
| 主题切换 | 280ms | ease | 背景/文字/边框/阴影 |
| 卡片 hover | 200–240ms | `cubic-bezier(.22,.9,.3,1)` | `translateY(-2~-4px)` + 阴影 |
| 开关 | 220ms | `cubic-bezier(.4,1.4,.6,1)` | 滑块带轻微回弹 |
| 视图切换 | 320ms | 同上 | 淡入 + 轻微上移 |
| Toast | 300ms in / 250ms out | `cubic-bezier(.22,1.2,.36,1)` | 底部居中 |
| 抽屉 | 340ms | `cubic-bezier(.22,.9,.3,1)` | 右侧滑入 |
| 场景执行 | ~700ms 模拟 | — | 运行中徽标 2.6s 后消失 |

减少动效偏好：可将 `theme-anim` 类相关 transition 降为 0（未来可选 `prefers-reduced-motion`）。

## 8. 组件规范

### 8.1 窗口标题栏

- 高 **48px**，背景 `--bg`
- 左：Logo 22px 圆角方块 + 「米家 · 控制中心」13px/650 + 副标 11.5px
- 中：搜索框 h32 r10，占位「搜索设备、场景、房间…」
- 右：主题切换 36×36 → 最小化 / 最大化 / 关闭（各 46×48）
- 关闭 hover：`#E81123` 底 + 白图标
- 支持 `-webkit-app-region: drag`（桌面容器）

### 8.2 侧栏导航项

| 状态 | 样式 |
|------|------|
| 默认 | `--text-2`，无底 |
| Hover | `--surface` 底，`--text` |
| 激活 | `--accent-soft` 底 + `--warm-text` 字 + 左侧指示条 |
| 徽标 | 10.5px 胶囊，`--surface-5` 底 |

### 8.3 按钮

| 类型 | 样式 |
|------|------|
| Primary | 紫渐变底、白字、h34 r10、紫投影；hover 亮度↑ + `translateY(-1px)` |
| Ghost | `--card-2` 底、`--text-2` 字；hover 变 `--hover` |
| Icon | 34×34 r10，`--card` 底 |

### 8.4 开关 Switch

- 轨道 **40×22** r22，关闭 `--track`
- 滑块 16px，关闭 `--thumb`
- 开启：`--accent` 纯色（无渐变也无硬描边），滑块右移，**无外发光**
- 大号（抽屉）：52×30

### 8.5 滑条 Range

- 轨道高 **5px** r6
- 已填充：`--accent`；未填充：`--slider-rest`
- 滑块：14px 白圆 + 轻投影
- 右侧读数：11.5px tabular，宽约 34px 右对齐

### 8.6 设备卡片

```
[图标 42×42 r13] [名称 13.5/650]          [开关]
                 [房间 · 开启状态 11.5]
                 [底部：功率/数值/滑条]
```

| 规则 | 说明 |
|------|------|
| 边框 | **无** |
| 默认底 | `--card` + 轻投影 |
| 开启底 | 淡紫渐变（见 §2.4） |
| Hover | 上浮 2px + `--shadow` |
| 图标底 | 默认 `--surface`；开启 `--accent-soft` |
| 网格 | `minmax(232px, 1fr)`，gap 13px |

### 8.7 统计卡片

- 图标 42×42 r13 + 标签 12 + 数值 21/700 + 注脚 11  
- 四色语义图标底：绿/紫/蓝/紫软色  
- 同设备卡：无边框、轻投影

### 8.8 场景卡

| 尺寸 | 用途 |
|------|------|
| 迷你（首页条） | r16，图标 38，标题 13.5，光晕默认 .28 |
| 大卡（场景页） | r20，图标 46，标题 16，描述 12，「立即执行」 |

- 底：场景色低透明度渐变 + `--card`
- 执行中：右上「运行中 ✓」徽标（绿 soft）
- **无边框**

### 8.9 自动化行

```
[图标 44] 名称 + Tag(条件/定时/动作)
          当 [条件] → [动作]
          运行状态 · 今日触发 · 延迟          [开关]
```

- 整行卡片式，无分割线  
- 条件胶囊：`--surface` 底 r7

### 8.10 抽屉（设备详情）

- 宽 **380px**，右侧滑入，底 `--drawer-bg`
- 头部：关闭钮 + 56px 图标 + 名称 + 元信息（**无分割线**）
- 区块：电源大开关、温控步进、模式胶囊、设备信息列表
- 行间距靠 padding，不用 `border-top`

### 8.11 Toast

- 底部居中，白/深色卡底 r12，强阴影  
- 左侧 7px 绿点 + 文案 13/600  
- 停留约 2.4s

### 8.12 芯片 Chip

- 高 32，全圆角，`--card` 底  
- 激活：`--accent-soft` + `--warm-text`（无描边）

## 9. 图标

- 线性 SVG，`stroke-width` 1.6–1.8，圆头圆角连接  
- 尺寸：导航 17 · 设备/统计 20–21 · 场景 19–23 · 标题栏 12–15  
- 开启设备图标色：`--accent-2`；默认：`--text-2`  
- 不使用彩色多色图标（除场景装饰色底）

## 10. 主题切换

| 项 | 规范 |
|----|------|
| 入口 | 标题栏主题钮 · 设置「外观」· 快捷键 `T` |
| 存储 | `localStorage['mijia-theme']` = `light` \| `dark` |
| 首次 | 跟随 `prefers-color-scheme` |
| 过渡 | `.theme-anim` 类 280ms 后移除 |
| 图表 | 切换后重绘网格/标签色 |
| `color-scheme` | 深色 `dark` / 浅色 `light`（滚动条等原生控件） |

---

## 11. 可访问性

- 文字与底对比：主文字在双方主题下均达可读对比（深色近白 / 浅色近黑）
- 可点击控件均有 hover 反馈；开关有视觉状态（位置 + 颜色）
- 输入框 focus：`box-shadow: 0 0 0 2px var(--accent-soft)`（不靠边框）
- 数字使用 tabular-nums，避免跳动
- 快捷键：`1–6` 切视图，`T` 主题，`Esc` 关抽屉

---

## 12. Do / Don't

| ✅ Do | ❌ Don't |
|------|---------|
| 用底色 + 轻投影分层 | 卡片加 1px 实线边框 |
| 开启态用淡紫渐变底 | 顶部彩色色条 / 硬紫描边 |
| 分区标题独立成行 | 标题右侧长横线 |
| 侧栏留白加大 | 密排 + 底部分割线 |
| 内容面板四角圆角 | 仅底部圆角、与标题栏粘死 |
| 冷紫作唯一系统强调色 | 大面积暖橙 / 多主色打架 |
| 场景可用多彩标识色 | 场景色蔓延到全局 UI |
| 数字 tabular + 收紧字距 | 比例数字导致跳动 |
| 无边框列表用间距分组 | 每行 border-top 刷屏 |

## 13. CSS 变量速查（开发用）

```css
/* 结构 */
--bg --panel --card --card-2 --hover
--line --line-2
/* 文字 */
--text --text-2 --text-3
/* 强调 */
--accent --accent-2 --accent-soft --warm-text
/* 功能 */
--green --green-soft --blue --blue-soft --amber --purple --cool
/* 圆角 */
--r-lg:20px --r:16px --r-sm:12px
/* 阴影 */
--shadow --shadow-strong
/* 开启态 */
--dev-on-bg --dev-on-border
```

实现文件中所有组件色应引用上述 Token，避免写死十六进制（场景标识色与品牌渐变除外）。
